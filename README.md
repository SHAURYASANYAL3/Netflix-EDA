# Netflix Movies & TV Shows - Exploratory Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset as part of the Pluto Academy Internship Project 01.

## Objectives
- Understand dataset structure
- Handle missing values
- Perform data cleaning
- Explore content trends
- Generate visualizations
- Derive business insights

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Key Insights
- Movies significantly outnumber TV Shows on Netflix.
- The United States contributes the largest share of content.
- Drama and Comedy are among the most common genres.
- Netflix content additions increased rapidly before slowing around 2020.
- Average movie duration is approximately 115 minutes.
